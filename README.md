# CSS Grid: сетка 2×3

Учебная задача по CSS Grid: сетка 700×400 px из двух равных колонок и трёх строк, средняя строка фиксированной высоты.

**Решение:** [src/App.css](src/App.css): `grid-template-columns: repeat(2, 1fr)`, `grid-template-rows: 1fr 200px 1fr`, `gap: 20px`.

Стек: HTML, CSS (Grid), тесты Playwright со скриншотным сравнением.

## Условие задачи

В файле `src/App.css` опишите стили для вёрстки из файла `src/index.html`

1. Файл `index.html` редактировать нельзя
2. Контейнер должен быть гридом размером `700px x 400px`
3. gap - 20px
4. Элементы располагаются в три строки, первая и третья занимают одинаковое место по оси Y, вторая - 200px
5. Элементы располагаются в два столбца одинаковой ширины
6. Цвет элементов - `#DAA520`

## Запуск
